Jira Setup Creating the project, statuses, issue types, and transition IDs

Step 1 — Create the Jira Project

Project Configuration

Create a new Jira project with a short, memorable project key (e.g. PRJ). This key appears in all ticket IDs and commit messages.

Use a Company-managed project type for full control over the workflow configuration. Team-managed projects have limited status customisation.

Step 2 — Create Issue Types

Required Issue Types
Issue TypePurposeWorkflow
DeliverableFeatures that flow through the full pipeline13-status pipeline
TaskWork breakdown items within a DeliverableBacklog → In Progress → Done
InitiativeHigh-level grouping of DeliverablesSimple workflow
IssueBugs and defectsSimple or pipeline workflow

Only Deliverables flow through the full 13-status pipeline. Tasks use a simple 3-status workflow. This separation is critical — child Tasks are work breakdown items within each Deliverable and do not need independent testing stages.

Important: The status names in Jira must match exactly what the pipeline configuration references. If Jira uses "Selected for Development" instead of "Ready for Dev", you must update the polling queries in CLAUDE.md to match. A mismatch will cause the Team Lead to find no tickets.

Step 4 — Configure the Workflow

Workflow Transitions

Configure the Deliverable workflow so that tickets can transition between all statuses. The Team Lead needs to be able to move tickets forward and backward through the pipeline.

Ensure transitions exist for:

  • Forward: each status to the next in sequence
  • Backward: each "In..." status back to its corresponding "Ready for..." status (for failures)
  • Reset: any status back to Backlog (for human override)

Step 5 — Retrieve Transition IDs

Getting the IDs

After creating all statuses and configuring the workflow, you need to retrieve the transition IDs. These are the numeric IDs that the Atlassian MCP uses to transition tickets programmatically.

In a Claude Code session with the Atlassian MCP connected, run:

getTransitionsForJiraIssue(cloudId: "your-cloud-id", issueIdOrKey: "PRJ-1")

This returns all available transitions for that ticket. Note the ID for each transition target and record them in the transition table in your CLAUDE.md file.
