Jira + Claude Code Pipeline Configuration guide for automated development, testing, and deployment

What This Is

A complete, reproducible configuration for running an automated software development pipeline using Jira for ticket management and Claude Code agent teams for implementation, testing, and deployment. Every ticket flows through a progressive confidence pipeline where specialist agent teams handle each stage, gated by evidence-based criteria and two human checkpoints.

Follow the pages in order. Each page covers one aspect of the setup:

  1. Prerequisites — what you need installed and configured before starting

Starter Templates

All configuration files live in the starter/starter-team/ directory. When setting up a new project, copy these templates and replace the {PLACEHOLDER} values with your project-specific configuration.

    SOLUTION-ARCHITECT-INPUTS.md — Inputs checklist
