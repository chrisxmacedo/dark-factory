Vision Statement

Vision Statement
A persistent, immersive 3D environment where the entire software delivery lifecycle — from ticket to production — is spatially visible, always live, and immediately intuitive. Features flow through the space as physical objects: consumed by AI agents, transformed into builds, and deployed onto environment surfaces. The pipeline becomes something you watch, not something you query — an operational control room for AI-augmented software delivery.
02

Design Principles

  • The vision prioritises passive observation over active interaction — the default state is watching, not clicking
  • The spatial metaphor is not decorative — position, movement, and visual state encode meaningful pipeline data
  • The system must work at the speed of the pipeline — real-time updates, not polling intervals
  • Accessibility is non-negotiable — the full experience must work on desktop browsers without VR hardware
  • The product is designed for the emerging reality of AI-first development where humans supervise, not execute
Spatial Awareness
Pipeline state encoded spatially — position, colour, and movement convey status without reading dashboards.
Real-time Data
WebSocket push from Jira, GitHub, and deployment platforms. The scene is always live, never stale.
Desktop + VR
WebXR-native with full desktop 3D fallback. Works on Quest, Vision Pro, or any browser.
Environment Panes
Test and production shown as transparent vertical planes with architecture components mapped to real infrastructure.

06

Build Roadmap

Incremental build phases, each delivering a usable increment. Each phase builds on the previous and can be deployed independently.

Phase 1 — Static Prototype
Hard-coded boxes in R3F with spatial layout. Get visual language right. No live data.
Scene layout · Box rendering · Environment panes · Camera controls
Phase 2 — Live Jira Data
Connect Jira integration. Render real tickets as boxes with labels, priority colours, and size.
Jira connector · REST API polling · Box mapping
Phase 3 — WebSocket Pipeline
Orchestration server with WebSocket push. Boxes move between zones in real time.
Node.js server · WebSocket · GitHub connector · State broadcasting
Phase 4 — Environment Panes
Map real architecture to test/prod panes. Deployment events light up components.
Architecture config JSON · Deploy connector · Component state
Phase 5 — Animations
Smooth transitions between stages. XState for choreography. Particle effects for deploys.
XState · Spring animations · Particle systems · Spatial audio
Phase 6 — VR Mode
WebXR session handling. Hand tracking. Gaze-to-inspect for ticket details. Room-scale support.
@react-three/xr · Hand tracking · Gaze interaction · VR UI panels
